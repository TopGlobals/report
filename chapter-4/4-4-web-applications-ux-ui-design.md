## 4.4. Web Applications UX/UI Design

### 4.4.1. Web Application Wireframes

**Login**

- **Description:** This screen displays the form where the user enters their credentials to access the application's home screen.

<img src="assets/wireframe-1.jpg">

**Dashboard** 

- **Description:** This screen displays the most important metrics for laboratory systems, such as temperature, ventilation, and foreign object detection, among others. This information is presented in graphs and short lists to make it easier to understand.

<img src="assets/wireframe-2.png">

**Laboratories** 

- **Description:** On this screen, a card grid layout was chosen to display the laboratories registered in the system, along with summary information for each one, such as temperature and location, among other details.

<img src="assets/wireframe-3.jpg">

**Lab Details** 

- **Description:** This screen displays detailed information about each laboratory, including real-time graphs of key metrics such as temperature and ventilation, among others. It also shows the laboratory's status indicators, active schedules, and recent activity.

<img src="assets/wireframe-4.jpg">

**Notifications and Alerts**

- **Description:** This screen displays the alerts generated by the system. To display them, we opted for a column of cards, where each card represents an alert and includes summary information such as the alert message and its priority, among other details. To view detailed information about an alert, a side panel appears on the right when you click on it.

<img src="assets/wireframe-5.jpg">
