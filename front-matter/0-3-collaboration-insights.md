## Project Report Collaboration Insights

Report Repository URL: [TopGlobals/report](https://github.com/orgs/TopGlobals/repositories)


The report was developed collaboratively in the team's GitHub organization following a docs-as-code approach. Each section of the report is a Markdown file stored in the folder of its chapter, together with its images. The work was organized with GitFlow: the `main` branch keeps the delivered versions, `develop` integrates the sections, and each member worked on a feature branch per section (for example, `feature/4-6-software-architecture`) that was merged into `develop` once completed. Every change was recorded with Conventional Commits, so the history of the repository shows which member wrote each part of the report. The activities and authors described below are consistent with the Report Version History.

**AV1**

For the first delivery, the team created the repository and wrote Chapters I to IV of the report.

- Arizabal Condori, Jean Niels
	- Wrote Chapter I (introduction and hypothesis statements) and Chapter II (competitive analysis with strategies and tactics, interviews for both segments with their video links and analysis, user personas, empathy maps, journey maps, the user task matrix and the ubiquitous language).

- Homola, Tomas
	- Wrote the landing page UI design (introduction, wireframe and mock-up, including the call-to-action section and the footer) and the information architecture section, and added the web application screenshots.

- Padilla Merino, Mauricio Jared

- Reyes Munoz, Joaquin Leonardo
